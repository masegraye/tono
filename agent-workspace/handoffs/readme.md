# handoffs

Written at the end of a working session, so that a new agent or person can pick up where the last one left off.

Naming: `handoff-<yyyy-mm-dd>-<slug>.md`

The date is the sequence. For more than one session in a day, add a counter to the slug.

Each handoff covers:

- **What happened**: the work done this session
- **Current state**: the branch, what is running, what is installed
- **Next steps**: what the next session should do
- **Gotchas**: anything the next agent would not guess
