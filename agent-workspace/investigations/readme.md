# investigations

Audits and analyses of what exists: what another client does that Tono doesn't, what a part of the code really does, what would be needed for something. Grounded in evidence (files and lines, documents, things that were run), and changing no code.

Naming: `inv-<nnn>-<slug>.md`

An investigation records findings and may recommend, but it is not a work order. What should be acted on becomes a backlog entry or a spec that refers back to it ("informed by inv-001").
