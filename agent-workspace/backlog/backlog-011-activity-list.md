# backlog-011: Activity as a list

| | |
|---|---|
| Status | captured |
| Area | Knowing what happened |
| Size | medium |
| Source | inv-001 |

## What

A list of every tab that needs you, failed, finished or is working, across hosts, grouped by priority or by session, with how long each has been so.

## Why

The sidebar's activity filter shows which tabs are active. It doesn't order them by what needs attention first or say for how long.

## Builds on

The activity states Tono already tracks. Rex Rune's rules for ages and for what the count includes are in `docs/configuration.md` under Activity.

## Promote when

When the sidebar filter stops being enough.
